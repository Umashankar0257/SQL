# 1. SQL FUNDAMENTALS

## What is SQL?

SQL stands for **Structured Query Language**.

SQL is used to:

- Retrieve data
- Insert data
- Update data
- Delete data
- Create database objects
- Modify database objects
- Control transactions
- Query relational databases

```sql
SELECT *
FROM Employee;
